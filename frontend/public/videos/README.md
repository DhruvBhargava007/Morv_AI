# Videos Directory

Place your demo video here as `morv-demo.mp4` for it to appear on the marketing landing page.

The video should:
- Be in MP4 format
- Have a 16:9 aspect ratio (recommended: 1920x1080 or 1280x720)
- Be optimized for web (compressed but high quality)
- Show the system in action, maintenance workflows, or digital twin visualizations

If no video is present, the page will show an animated placeholder with system diagnostics.
